# AI辅助、个人贡献与验证

用户提供考核规范、所选企业知识问答题和DeepSeek接口授权，并亲自在浏览器完成GitHub账号登录。当前没有证据表明用户手工编写或修改了项目代码，不将AI产出写成候选人独立实现。

Codex参与：检查和配置Python/GitHub环境，设计原生动作循环、合成资料与检索方式，编写代码、测试和文档，运行真实DeepSeek与离线评估，分析并修复并行工具调用兼容问题，准备GitHub交付。企业资料均合成，未上传真实企业数据。

运行时AI使用DeepSeek的deepseek-flash，在每轮基于真实观察选择动作和证据。它与开发时的Codex辅助是两个不同角色；offline_mock为确定性测试替身，不作为真实模型决策证据。没有提交模型内部思维过程。

验证不只看AI描述：实际运行pytest、pip check、11组真实模型案例、11组离线案例和检索对比，记录对应输入、完整资料快照、输出与Trace，见docs/03-evaluation.md。初版失败材料保留在examples/experiments/。

密钥仅保存在被忽略的本机.env，不写入代码、Trace、命令示例或GitHub。日志只记录模型名和token使用量，不记录授权头。候选人在正式提交前应亲自运行、审阅引用与失败边界，并据实补充个人修改、学习收获和人工验证结果；当前不虚构这些贡献。

实际会话耗时记录见examples/work-session.json：使用工具记录的起止时间计算会话墙钟时间，包含交互、等待和模型调用，不等同候选人独立编码耗时。10月28日环境准备与本次业务开发分开记录。
